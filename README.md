# Bundled fonts

- **KFGQPC-Hafs.ttf** — "KFGQPC HAFS Uthmanic Script", the Madani mushaf
  typeface by the King Fahd Glorious Quran Printing Complex
  (fonts.qurancomplex.gov.sa). Used as the primary Arabic font, rendered
  with HarfBuzz shaping. License: free of cost to use, copy and
  distribute; may not be sold, modified or reverse-engineered.
  © King Fahd Glorious Quran Printing Complex.
- **NotoNaskhArabic.ttf** — Google Fonts, SIL Open Font License 1.1.
  Fallback Arabic font for environments without the HarfBuzz renderer.
- **AmiriQuran-Regular.ttf** — Amiri Quran, SIL Open Font License 1.1.
  Legacy primary font (Pillow libraqm path).
- **FreeSerif.ttf** — GNU FreeFont, GPLv3 with font exception.
  Last-resort fallback.
